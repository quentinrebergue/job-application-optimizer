# data/general-questions

Global Q&A flashcards not tied to a specific entity. Used by the Q&A Trainer when scope is set to "general".

## File Convention

Each question is a single JSON file named `gq-{id}.json`.

## Schema

```json
{
  "id": "gq-001",
  "question": "...",
  "answer": "...",
  "tags": ["..."]
}
```

## Seed Data

| File | Topic |
|------|-------|
| `gq-001.json` | Tell me about yourself |
| `gq-002.json` | Why do you want to work here? |
