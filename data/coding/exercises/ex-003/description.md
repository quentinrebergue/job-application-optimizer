# Longest Substring Without Repeating Characters

Given a string `s`, return the length of the longest substring that contains no duplicate characters.

**Example 1:**
```
Input:  s = "abcabcbb"
Output: 3   ("abc")
```

**Example 2:**
```
Input:  s = "bbbbb"
Output: 1   ("b")
```

**Example 3:**
```
Input:  s = "pwwkew"
Output: 3   ("wke")
```

**Constraints:**
- 0 ≤ s.length ≤ 5 × 10⁴
- `s` consists of English letters, digits, symbols, and spaces
