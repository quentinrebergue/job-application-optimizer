# src/types

TypeScript type definitions for the entire application. All types are barrel-exported from `index.ts`.

## Files

| File | Description |
|------|-------------|
| `index.ts` | Barrel export — re-exports all types from this directory |
| `entity.ts` | `EntityType`, `ExperienceMeta`, `ProjectMeta`, `SkillMeta`, `EducationMeta`, `EntityMeta` (union) |
| `job.ts` | `ApplicationStatus`, `AIRanking`, `AIAnalysisResult`, `ResumeConfig`, `JobOffer`, `JobWithConfig` |
