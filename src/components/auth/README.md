# src/components/auth

The forms of the public account pages; each submits a Server Action of `src/app/actions/`.

| File | Description |
|---|---|
| `AuthForm.tsx` | The sign-in and sign-up form |
| `ForgotPasswordForm.tsx` | Asks for the mail with the reset link |
| `ResetPasswordForm.tsx` | Sets the new password from the reset link |
| `ResendVerificationButton.tsx` | Sends the confirmation mail again |
